Ioquake3

Ioquake3 is an encyclopedia entry in the Game engines collection.

id Tech 3, originally known as the Quake III Arena engine, is a game engine developed by id Software for its 1999 game Quake III Arena. It has subsequently been used in numerous games. Commercially, id Tech 3 competed with early versions of the Unreal Engine; both were widely licensed. Originally proprietary, it is now open-source software.
