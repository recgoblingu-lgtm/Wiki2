Background

Pspell ( P ortable Spell Checker Interface Library) is a program meant to provide a generic interface to the system spelling checking libraries. It was, and sometimes still is, used in computer programming such as C , and is licensed under the GNU Lesser General Public License . Pspell has not been updated since 2001, but is still available on SourceForge at its project page . It has been replaced by GNU Aspell . PHP ’s Pspell extension, while retaining its current name, now uses the Aspell library.
