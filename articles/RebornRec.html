RebornRec

RebornRec is an encyclopedia entry in the Rec Room revivals collection.

RebornRec is a publicly documented, locally hosted server project for preserving older Rec Room builds from approximately 2016 through 2020. Its public repository describes server emulation features and notes that it is an independent project rather than an official Rec Room product.
