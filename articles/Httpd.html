Background

HTTPd is a software program that usually runs in the background (i.e. a so-called " daemon "), as a process , and plays the role of a server in a client–server model using the HTTP and/or HTTPS network protocol (s). The process waits for the incoming client requests and for each request it answers by replying with requested information, including the sending of the requested web resource , or with an HTTP error message .
