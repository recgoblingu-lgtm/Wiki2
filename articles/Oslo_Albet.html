Oslo Albet is an encyclopedia entry in the Indie games collection.

Fireboy and Watergirl is a video game franchise developed and published by indie game developer Oslo Albet using the discontinued multimedia software platform Adobe Flash, converted to HTML5. The game features the titular main characters Fireboy and Watergirl as they traverse through multiple temples.
