Mappy World

Mappy World is an encyclopedia entry in the Mobile games collection.

Mappy World is a mobile phone game released in 2011 by Namco Bandai Games in Japan only. It is a remake of the arcade game Mappy and features several enemies and mechanics from the original title.

Background

Mappy World ( マッピーワールド , Mappī Warudo ) is a mobile phone game released in 2011 by Namco Bandai Games in Japan only. It is a remake of the arcade game Mappy and features several enemies and mechanics from the original title.
