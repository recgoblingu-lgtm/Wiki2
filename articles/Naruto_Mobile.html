Naruto Mobile

Naruto Mobile is an encyclopedia entry in the Mobile games collection.

Naruto Mobile is a free-to-play side-scrolling action fighter mobile game developed by More Fun Studio and published by Tencent Games, created with licensing and IP support from Bandai Namco Games. The game features a strong focus on player-versus-player (PvP) combat and animation effects. Production oversight is provided by Naruto creator Masashi Kishimoto along with the production committee consisting of Shueisha, TV Tokyo, and Studio Pierrot.
