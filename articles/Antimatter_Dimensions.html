Background

Antimatter Dimensions is a 2016 game created by Finnish developer Hevipelle. It is an incremental game in which the user uses earned antimatter to purchase dimensions that automatically produce more antimatter, alongside upgrades which increase antimatter production. Similar to other incremental games, the game lacks a conventional ending, instead allowing players to restart the game by reaching infinity antimatter and then initiating a universe collapse to accelerate progression. An achievement system with secret achievements is also present, along with a custom scripting language to automate some aspects of the gameplay. The game stopped receiving updates in June 2018, but in December 2022, Antimatter Dimensions was ported to Steam along with an update named the "Reality Update", adding late-game progression elements. The game is also available on Android .

Gameplay

To progress, the player buys dimensions to start antimatter production. After the player purchases the fourth dimension, the player can reset the game to gain a production multiplier. This goes on until the eight dimension is unlocked. Along the way, tickspeed upgrades are revealed which speed up antimatter production. Antimatter galaxies can be bought. When the player reaches infinity antimatter, the player can collapse the universe to gain infinity points, which can be spent on upgrades.
